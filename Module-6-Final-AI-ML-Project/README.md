# Student Performance Prediction using Machine Learning

## 📌 Project Overview

This project is the final AI & Machine Learning project completed as part of my Codomax AI & ML Internship.

The project uses student academic and study-related information to train a Machine Learning model that predicts a student's final performance.

A Linear Regression model is used to predict the final grade based on selected features from the student performance dataset.

---

## 🎯 Problem Statement

Student academic performance can be influenced by several factors such as study time, previous grades, number of failures, and absences.

The objective of this project is to use Machine Learning to analyze these factors and predict a student's final grade.

---

## 🎯 Project Objectives

- Load a real-world student performance dataset.
- Explore and understand the dataset.
- Check and clean the data.
- Select relevant features for prediction.
- Visualize relationships within the data.
- Split the dataset into training and testing sets.
- Train a Machine Learning model.
- Evaluate the model performance.
- Predict the performance of a new student.
- Interpret the predicted result.

---

## 📊 Dataset

The project uses the **Student Performance Dataset** from the UCI Machine Learning Repository.

The Mathematics student performance dataset is accessed directly from an online ZIP file using Python.

The dataset contains information about students, including:

- Study time
- Previous failures
- Absences
- First period grade (G1)
- Second period grade (G2)
- Final grade (G3)

The target variable used in this project is:

`G3` – Final Grade
