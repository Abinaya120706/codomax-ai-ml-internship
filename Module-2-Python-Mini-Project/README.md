Student Grade Calculator

📌 Project Overview

The Student Grade Calculator is a beginner-friendly Python project developed as part of Module 2 – Python Mini Project of my Codomax AI & ML Internship.

The application accepts a student's name and marks for different subjects, calculates the total marks and average, and determines the student's grade based on the average score.

🎯 Objectives

Apply Python fundamentals learned in Module 1.

Practice variables, lists, loops, functions, and conditional statements.

Perform basic mathematical calculations using Python.

Build a simple interactive Python application.

Handle invalid input using basic error handling.


✨ Features

Accepts the student's name.

Accepts marks for multiple subjects.

Validates marks between 0 and 100.

Calculates total marks.

Calculates average marks.

Determines the grade automatically.

Displays the final result clearly.

Handles invalid numerical input.

⚙️ How the Program Works

1. The user enters the student's name.


2. The program displays the subjects.


3. The user enters marks for each subject.


4. The program validates the entered marks.


5. The total marks are calculated.


6. The average marks are calculated.


7. A grade is assigned based on the average.


8. The final result is displayed.
